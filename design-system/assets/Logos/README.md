# Logos

No logo file exists in the pb project. The search covered `*logo*`, `*.svg`, `*.png` and `*.ico` outside `.git`. Nothing was copied, and no logo was drawn.

The landing mark is type plus a CSS shape:

- Wordmark: the text `pb`, set in the system-ui stack, weight 700, 1.6rem, tracking -0.5px, colour #FFFFFF (docs/index.html:41-46).
- Butter pat: a 22 by 16px rounded rectangle, 3px radius, #FFD966, rotated -4deg, with a soft shadow (docs/index.html:33-38). It is CSS, not an image file.

If a logo file is added later, copy it here with `cp` and add one entry per file: what it is, its ink colour, and its minimum size.
